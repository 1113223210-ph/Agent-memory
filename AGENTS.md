# AGENTS.md

## Commands

All commands run from this directory:

```bash
npm install
npm run dev
npm run build
npx tsc --noEmit
```

## Notes

- Dev server runs on `http://localhost:3201`
- App uses Next.js App Router with static export enabled
- Tailwind CSS is configured via `postcss.config.mjs`
- The site is intentionally a single-page Chinese-first memory field guide
